# AI Resume Screening Agent

基于大语言模型的简历筛选与评估 Agent。

## 项目简介

本项目尝试使用大语言模型完成招聘 JD 与候选人简历的结构化分析，并通过固定 Rubric 对候选人进行多维度评估。

项目重点不是简单调用大模型进行“打分”，而是尝试将：

**JD解析 → 简历解析 → 证据提取 → Rubric评分 → Python规则校验 → 加权评分 → 候选人排序**

串联成一个完整的 AI Agent 流程。

## 核心功能

* 招聘 JD 结构化解析
* PDF / DOCX / TXT / Markdown 简历解析
* 图片及扫描版 PDF 的视觉模型解析
* 多份候选人简历批量分析
* 基于 Rubric 的多维度评分
* 评分证据提取
* A / B / C / D 证据等级
* Python 二次评分校验
* 自定义评分权重
* 候选人综合评分与排序
* JSON 分析结果导出

## 评分维度

当前包含六个评价维度：

| 维度     | 默认权重 |
| ------ | ---: |
| 学历匹配   |  10% |
| 工作经验   |  15% |
| 岗位相关经验 |  25% |
| 核心技能   |  20% |
| 项目经验   |  15% |
| 职责匹配   |  15% |

总权重为 100%。

## Rubric 与证据等级

评分采用固定分档：

**0 / 2 / 4 / 6 / 8 / 10**

同时根据证据强度设置：

* **A**：直接、明确的简历证据，最高 10 分
* **B**：高度合理的间接判断，最高 8 分
* **C**：存在一定相关性，但证据较弱，最高 6 分
* **D**：没有有效证据，0 分

模型生成初始评分后，由 Python 对评分进行二次校验，避免出现证据等级与分数不一致的情况。

## 技术栈

* Python
* Streamlit
* OpenAI-compatible API
* PyMuPDF
* python-docx

项目支持使用不同的 OpenAI-compatible API 供应商进行测试。

## 本地运行

安装依赖：

```bash
python -m pip install -r requirements.txt
```

启动：

```bash
python -m streamlit run app.py
```

启动后在浏览器访问 Streamlit 提供的本地地址。

## 项目定位

这是一个个人 AI Agent 实践项目，主要用于探索：

* LLM 应用开发
* AI Evaluation
* Rubric 设计
* Evidence-based Evaluation
* 大模型输出约束
* Agent 流程设计
* 不同模型的结果比较

## 注意事项

本项目不提供真实招聘数据。

请勿上传包含真实姓名、联系方式、身份证件或其他敏感个人信息的简历。

使用第三方模型 API 时，请注意相关服务商的数据处理政策及 API 使用成本。
